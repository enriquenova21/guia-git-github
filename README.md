# Guía de Git y GitHub con IA

Página web interactiva que explica cómo subir un proyecto a GitHub, paso a paso.
Hecha con HTML, CSS y JavaScript, con ayuda de IA.

Incluye:
- Checklist de pasos con barra de progreso (se guarda en el navegador)
- Buscador de comandos con filtros y botón de copiar
- Mensajes de ejemplo para aprender Git con IA
- Preguntas frecuentes sobre errores comunes

Abre `index.html` en el navegador para verla.
