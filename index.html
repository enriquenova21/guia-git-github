Qué es cada cosa

Git

Programa que corre en tu computadora y guarda el historial de tu proyecto. Cada commit es una foto de tus archivos en ese momento, con un mensaje que explica qué cambió.

GitHub

Sitio web donde guardas tus repositorios en internet. Sirve de copia de seguridad, de portafolio y para trabajar en equipo.
